# Бендер

Постоянно живущий ИИ-агент на своей машине: разговор, память и поиск, таймеры и сон, помощники, Telegram/почта, модели по API и подпискам, MCP, навыки и модули. Пульт на русском; ядро — стандартная библиотека Python 3.10+, без сторонних пакетов.

Агент учится навыкам и пишет отдельные модули; своё ядро не правит. Codex CLI как движок заблокирован до подтверждения запрета встроенных тулов. Проверенные пакеты используют слоты; git-клон обновляется своей веткой после бекапа и самопроверки.

Автозапуск: `bender service install`, состояние — `bender service status`, удалить — `bender service remove`. Используется systemd пользователя или Termux:Boot; установленный голос подключается отдельно: `bender service install --voice`. Если уже работает ручная копия, команда включит будущий автозапуск и назовёт её PID, не запуская вторую. Пульт → Состояние запуска показывает способ запуска, кнопки перезапуска и выключения.

Локальные Уши и Голос: `bender voice install` ставит отдельный пакет и подключает постоянных агентов без своих аудиоцепочек. Уже установлен: `bender voice connect all` или кнопка «Подключить этому агенту» в Моделях. Голосовые ответы Telegram: `/voice reply`; агент может ответить тулом `speak`. Настройки CLI видны ядру без перезапуска.

Обновиться: `bender update` или «Версии и откат» → «Проверить обновления» → «Обновить программу». Только проверить: `bender update --check`. Для приватного GitHub сначала `gh auth login` и `gh auth setup-git`; токены Бендер не копирует.

Из скачанной папки на Linux/macOS/Termux:

```sh
bash install.sh
bender doctor
bender
```

На Windows — [install.bat](install.bat), затем ярлык «Бендер». Без установки — `python3 -m bender` из папки программы. Пульт по умолчанию слушает только свою машину. Ключи и бекапы без шифрования; сейф 0600 на POSIX.

- [Жизнь с Бендером](ЖИЗНЬ-С-БЕНДЕРОМ.md) — первый запуск, модель, каналы и восстановление.
- `bender doctor` — состояние и подсказки; `bender report` — просмотр состава и технический архив без личных текстов; `bender usage [--hours 24] [--model gpt]` — расход моделей по часам и видам ходов, только числа.
