# Matrix — транспорт хозяина

Этот пакет работает отдельным процессом на стандартной библиотеке Python. Ядро не импортирует его код. Установить — Связи → Matrix → «Установить Matrix в карантин»; затем в Модулях просмотреть и одобрить пакет, обнаружить и одобрить определения. Настройки, токен и код хозяина — в Связях, ручной конфиг не нужен.

Нужна отдельная учётная запись бота и отдельная комната без шифрования, в которой ровно бот и хозяин. Вход в указанную комнату выполняется только кнопкой хозяина. Не отключаем E2EE у существующей комнаты: для этого модуля создаётся другая. Olm/Megolm/верификация устройств не реализованы.

Транспорт использует HTTPS/системные сертификаты и унаследованный прокси; HTTP допускается лишь на localhost для локального сервера/проверок. Нет переходов по редиректам и автоматических повторов. Вложения — до 20 МБ, только MXC через аутентифицированный endpoint своего homeserver. Сообщения и реакции отправляются через уникальные transaction ID.

MCP-метод channel/configure — закрытый интерфейс транспорта ядра, не тул модели: адрес/комната и секрет передаются по stdin после проверки снимка. Обычный запуск пакета не имеет токена и не подключается сам. Долгий /sync не блокирует исходящую отправку: для операций разные процессы. Изменение настроек/ключа/пакета отзывает ожидание. Проверка: bender try matrix; явная сеть — bender try matrix check.
