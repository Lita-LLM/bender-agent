# Жизнь с Бендером

Бендер живёт на твоей машине: разговаривает, помнит, делает поручения и просыпается по расписанию. Настройка — через пульт; конфиги руками не нужны. Для первой проверки достаточно браузера и одной модели.

## Установить и запустить

Скачай репозиторий Бендера из основной ветки и распакуй в постоянную папку. Нужен Python 3.10 или новее. На Linux/macOS/Termux открой терминал в этой папке:

```sh
bash install.sh
bender doctor
bender
```

Установщик проверяет окружение, создаёт команду запуска и предлагает открыть браузер. Автозапуск добавляется отдельно через `bash install.sh --service`. На Windows запусти [install.bat](install.bat) и затем ярлык «Бендер». В командах ниже на Windows можно заменить `bender` на `python -m bender`, выполняя их из папки программы. Без установки:

```sh
python3 -m bender doctor
python3 -m bender
```

Обновиться: `bender update` или кнопка «Обновить программу» в «Версиях и откате» после проверки коммитов. `bender update --check` только проверяет; `bender update --yes` ставит показанные коммиты без вопроса. Клон обновляет свою отслеживаемую ветку, делает обычный бекап и doctor без запросов к моделям; плохая самопроверка возвращает прежний коммит, данные не откатывает. Локальные правки/расхождение ветки останавливают обновление. Если на сервере пересобрали историю, обновление остановится с ошибкой «Локальная ветка разошлась с сервером»: нажми «Выровнять с сервером» (в «Версиях и откате», `bender update --realign` или кнопка в Telegram `/update`). Прежний коммит сохранится в ветке `bender-before-realign-…`, перед сбросом будет бекап, после — самопроверка с возвратом при неудаче; свои незакоммиченные правки в папке программы мешают, коммиты не затрагиваются, пока ты их не вернёшь. Если эта версия Бендера ещё не умеет выравнивать (старая), вручную в папке программы: `git fetch origin && git reset --hard origin/main`, потом перезапусти Бендера; данные лежат отдельно и не затрагиваются. Основная папка бекапов не приняла снимок — он ляжет в запасную; не приняла и она — обновление остановится, ничего не поставив. Тогда нажми «Починить бекапы» в **Бекапах** или обнови без бекапа один раз: галочка «Без бекапа» у кнопки обновления, `bender update --no-backup`, кнопка в Telegram или настройка «Следующее обновление — без бекапа» (гаснет сама). Самопроверка и откат при этом остаются; если новая версия не прошла самопроверку, причина названа в ошибке. Если папка бекапов ещё не выбрана, разовый снимок лежит в ~/.local/share/bender/update-backups; состав тот же, секреты только по настройке бекапов. Из ZIP — распакуй свежую программу в новую папку и укажи прежнюю --data, сохрани старую до проверки.

Пока идёт обновление из пульта, под кнопкой виден текущий шаг: проверка папки, получение коммитов, бекап (сколько файлов пройдено и сколько прочитано), установка, самопроверка. Там же время шага. Самый долгий шаг — первый бекап большой папки данных (рабочие папки агентов, голос в `local/voice`). Следующие бекапы перечитывают только изменённые файлы. С экрана можно уйти: обновление идёт в Бендере, а итог прошлого обновления останется на экране «Версии». Если шаг стоит на месте дольше нескольких минут, сообщи название шага вместе с отчётом `bender report`.

Для приватного GitHub используй `gh auth login` и `gh auth setup-git`. В «Настройках → Версии» доступны off/notify/night: notify проверяет раз в сутки, night ставит во время сна по решению хозяина. Первое суточное уведомление после старта — через сутки; night может проверить уже в первый сон. Служба получает PATH установщика; после установки gh в необычную папку повтори `bash install.sh --service`. Обновление перезапускает свой Сторож/службу; без них попросит перезапустить вручную.

Пульт открывается по ссылке с токеном, которую Бендер печатает и открывает при запуске. Кука нужна даже на http://127.0.0.1:8770/. Получить ссылку снова: `bender link` (с той же `--data`, если папка другая). Если порт занят, ссылка содержит выбранный порт. Оставь процесс работающим. По умолчанию доступ есть только с этой машины. Для другого устройства включи «Пускать из локальной сети» и возьми сетевую ссылку из терминала. Ссылку держи при себе.

Данные по умолчанию в `data/` рядом с программой, отдельно от кода. Свою папку указывают **перед** командой, например `bender --data /путь/к/данным doctor`; используй одну и ту же папку при следующих запусках. Она содержит SQLite, личность, память, навыки, рабочие файлы и секреты. Ключи в `data/secrets.json` открытым текстом с правами 0600 на POSIX. Доступ Windows проверяется правами твоей учётной записи. Не отправляй всю папку агентам или в переписку.

## Познакомиться и выбрать модель

В знакомстве выбери новое существо или переезд прежнего, затем имя и способ подключения. В «Моделях» доступны API, локальный OpenAI-совместимый сервер, подписка ChatGPT и официальные Claude Code. Для подписки ChatGPT есть кнопка входа или `bender login chatgpt`; войди в открывшемся браузере по коду. У CLI сначала установи официальную программу и войди в неё сам, затем нажми проверку в пульте. Codex CLI как движок заблокирован; проверка его наличия не включает его.

Можно начать с бесплатной модели через OpenRouter или с локальной: бесплатность и доступность зависят от провайдера. Ключ вставляй в поле подключения, не в разговор. Нажми проверку, назначь **Главную** роль и пройди Пробуждение. Затем задай простое поручение. Дополнительные роли и запасные модели подключай позже; у «Ушей», «Голоса» и эмбеддингов свои цепочки, Главная их не заменяет. Укажи дневной бюджет в настройках, если нужны ограничения расходов.

Модель роли выбирается выпадающим списком из каталога провайдера; большой список можно искать, неизвестный id — «Ввести вручную…». «Обновить список» перечитывает каталог без разговора с моделью. Блок «Топливо» показывает последние измеренные окна и сбои; без данных процент неизвестен. Для OmniRoute кнопка читает сохранённые квоты по ключу с allowUsageCommand. Предупреждения на 85%/100% выключаются в Настройках → Топливо.

В разговоре с тобой стандартного предела шагов и времени больше нет; при желании задай его в Настройках → Агент (0 — без лимита). Безлюдные поручения и субагенты имеют отдельные пределы. Петля одинаковых результатов останавливается, длинная история сжимается по дороге с сохранением цели и дат. Ты всегда можешь нажать Стоп.

## Усилия моделей

`/effort` показывает выбранные и передаваемые уровни без вызова модели. `/effort high`, `/effort max` или `/effort low` меняют умолчание **текущего агента** для его текстовых ролей и запасных, включая API и фоновые задачи. `/effort default` оставляет решение провайдеру. Команда работает в пульте, терминале и Telegram; пересланный текст или расшифровка её не выполняют.

В **Модели → Усилия моделей этого агента** есть тот же выбор и выключатель. Для отдельной модели открой **роль → Усилия модели**, выбери уровень и нажми **Сохранить** в карточке роли. Этот выбор важнее общего умолчания. Можно независимо настроить основную и каждую запасную. У Ушей, Голоса и эмбеддингов этого переключателя нет.

Новый Claude получает настоящий `output_config.effort` вместе с adaptive thinking, ChatGPT — `reasoning.effort`, остальные API — свой формат. Пульт показывает, что пойдёт в запрос. Если выбранный уровень не поддерживается, он сохраняется, а для вызова подбирается доступный; **off не обещает выключить мысли у модели, которая этого не умеет**. Для посредника вроде OmniRoute открой «Формат усилий» и выбери поддерживаемый им вариант. В авто режиме неизвестный формат остаётся без параметра. Некоторые модели/серверы различают только on/off.

Большие усилия могут увеличить задержку и расход. Общие денежные лимиты действуют. Настройка не показывает и не скрывает текст размышлений: это отдельное поведение интерфейса. Проверка без сети — `bender try effort` и **Полигон → Усилия моделей**. Подробности и источники — [исследование провайдеров](docs/research/PROVIDERS.md#effort-разных-провайдеров--27-октября-2026).


## Где что находится

Не помнишь, где что лежит, — нажми лупу вверху пульта, Ctrl+K или `/`. Поиск знает все экраны, все настройки (с подсказками и вариантами), заголовки, поля и кнопки на экранах. Enter откроет нужный экран и подсветит место. Если в пульте ничего нет, последняя строка ищет то же слово в памяти агента.

- **Разговор** — сообщения, тулы, карточки одобрения, микрофон при включённом голосе. **Задачи** — помощники и их роли.
- **Личность** — имя, правила и лицо. **Память** — поиск, дневник, факты и инспектор происхождения. Правка поискового представления разговора сохраняет исходные сообщения.
- **Сердце** — напоминания, таймеры и задания. **Сны** — ночная обработка опыта; **Тело** — самочувствие и расходы.
- **Связь** — Telegram, почта, вебхуки и API. **Модели** — провайдеры и цепочки.
- **Навыки**, **MCP**, **Модули**, **Мастерская** — свои процедуры и отдельно проверяемые инструменты. **Полигон** проверяет каждую часть по отдельности.
- **Права** — Предохранитель (профиль, песочница команд, лимиты процессов) и запросы согласия. Память дочерних процессов по умолчанию не ограничена (0): прежний лимит 1 ГБ считал адресное пространство, а не реальную память, и ронял Node, Go, Java и браузеры. Выключатель «Учитывать недоверенный текст» убирает всё, что связано с «заражённым» ходом: лишние карточки после сайта или ответа MCP, подтверждение ответа в группу, пропуск разбора памяти. **Бортжурнал** — история решений. **Настройки** — выключатели.
- **Бекапы**, **Версии и откат**, **Самопроверка** — восстановление и разбор проблем.

После полезной работы напиши `/научись`: чистый текстовый навык пройдёт проверку и появится в каталоге; подозрительный пакет останется в карантине. Импортированные скрипты, модули и MCP требуют просмотра; одобрение пакета не разрешает все его действия. Внешняя программа без изоляции ОС может иметь права твоего пользователя. Doctor показывает доступный уровень; строгая Мастерская без bubblewrap закрыта.

## Браузер агента (превью)

«Настройки → Браузер агента» (выключено): агент открывает страницы в установленном Chrome, Edge или Chromium с отдельным профилем в папке данных (своя копия входов, не твой профиль). Тулы `browser_open`, `browser_look`, `browser_click`, `browser_type`. Страница приходит текстом с номерами элементов и считается недоверенной; нажатия и ввод проходят Предохранитель. Адреса `file:` и `chrome:` и сам пульт закрыты. По умолчанию без окна; «Без окна» выключи, чтобы смотреть. Другой браузер — переменная `BENDER_BROWSER` с путём.

Внешний клиент может прервать ход агента: `POST /v1/bender/stop` с тем же ключом, что у API, телом `{"model":"bender/имя","user":"id чата"}` (без `user` — все API-чаты агента).

## Antigravity (превью, на свой риск)

«Модели → Подключить → Antigravity»: Бендер запускает твой установленный `agy -p`. Google не поддерживает такие обёртки на личных планах и может заблокировать аккаунт, поэтому подключение просит подтвердить риск. Движок работает только с текстом и только для ролей без тулов Бендера (Быстрая, Чтец и подобные); встроенные инструменты agy обязаны быть выключены, иначе Бендер его не запускает. Проверка без вызова модели: `bender try agy`. Работа на настоящем agy не проверялась.

## Окна Windows (превью, не проверено)

«Настройки → Окна Windows»: включи и впиши программы, например `notepad.exe`. Агент видит только их окна (`screen_windows`), смотрит снимок (`screen_look`), нажимает и печатает (`screen_click`, `screen_type`); каждое нажатие и ввод спрашивают тебя карточкой. Терминалы, Telegram, менеджеры паролей, пульт, окно «Выполнить» и диспетчер задач закрыты всегда, даже если ты их впишешь. Работает только на Windows и пока ни разу не запускалось на настоящем: сообщи, что получится.

## Telegram и почта

В группе можно ограничить, кого бот видит: хозяин пишет там `/members add НОМЕР` (номер человека в Telegram, например от @userinfobot). Пока список не пуст, остальных участников бот не запоминает и в контекст не берёт; `/members remove НОМЕР` убирает человека, `/members off` снимает ограничение, `/members import` добавляет людей, перенесённых из OpenClaw (groupAllowFrom). Превью: `/members wake on` позволяет людям из списка звать бота упоминанием или ответом. Их слова недоверенные, бот только отвечает текстом и не делает действий с последствиями; выключено по умолчанию. Чтобы бот вообще получал обычные сообщения группы, в @BotFather выключи privacy mode или сделай бота администратором.

В «Связи → Telegram» вставь токен своего бота, включи канал и выполни показанную привязку хозяина. Проверь сообщение с телефона, одобрение кнопкой и стоп-кран. Токен не пиши в обычный чат. Почта необязательна: настрой IMAP/SMTP, проверь соединение и выбери, что делать с новыми письмами. Чужое письмо и пересланное сообщение остаются недоверенными, даже если их переслал хозяин.

Во время работы Telegram показывает временный черновик: статус, краткие мысли и текст; после него сохраняет один окончательный ответ. /stop прерывает работу агента и не блокирует его: следующее сообщение или команду он берёт сразу. /estop — стоп-кран: останавливает всё и не даёт агентам действовать до /resume. Кнопку «Стоп» под черновиком Бендер больше не просит у Telegram — она перекрывала ввод. Настройки → Telegram → Живой ответ: full/text/off. На старом сервере вместо черновика будет временный редактируемый статус. Мысли в пульте свёрнуты и раскрываются по желанию.

Если бот замолчал, загляни в «Связь → Telegram». Жёлтая плашка «Telegram попросил паузу» значит, что бот слишком часто писал в чат и Telegram временно запретил ему отправку. Сообщения и команды при этом доходят, а ответы уйдут, когда пауза кончится. Если такое повторяется, выключи живой ответ командой /live off. Красная плашка показывает ошибку связи. Неудачные отправки записываются в Бортжурнал. Долгая команда (/backup, /compact, /sleep tidy) не мешает остальному: /stop, /estop, /status, /help и кнопки одобрения срабатывают сразу. Следующее сообщение ждёт её не дольше 30 секунд.

Если бот молчал, а потом ответил на всё разом, открой Бортжурнал и найди записи канала Telegram за то время. Бендер сам пишет, где ждало опоздавшее больше чем на минуту сообщение. «Ждало конца идущего хода» значит, что агент был занят долгой задачей (запись скажет, чем именно: моделью, тулом или карточкой одобрения). Такое сообщение сразу получает 👀 — бот его видел и ответит в конце хода; прервать долгий ход можно командой /stop, писать дальше можно сразу. «Нет связи» и «связь вернулась» — обрыв до Telegram; после него бот пробует снова не реже раза в 30 секунд. Если причина «кто-то ещё опрашивает этим ботом», выключи второй Бендер или OpenClaw с тем же токеном. «Бендер стоял N с» — завис сам Бендер, место видно в записи, полный стек лежит в `local/stalls.txt` папки данных; пришли его разработчику. Если Бендер завис насовсем (процессор занят, пульт и бот молчат), через три минуты он сам запишет, где стоит, в `local/hang.txt`, выйдет и поднимется заново; после запуска придёт уведомление «Бендер завис и перезапустился», а запись переедет в `local/hang-last.txt` — её тоже пришли разработчику. Срок меняет переменная `BENDER_HANG_SECONDS` (0 — не выходить). «Опрос шёл исправно, Telegram отдал сообщение только сейчас» — задержка у Telegram или в сети до него.

На каждом канале есть выключатель. Стоп-кран вверху пульта останавливает деятельность агента; затем его можно снять. Он не завершает процесс и не стирает данные.

## Если что-то сломалось

Если doctor сообщает о повреждённых ссылках ролей, открой Самопроверку → «Починить ссылки в ролях». Удалятся кандидаты без действующего провайдера/модели; запись останется в журнале. В Моделях есть такая же починка выбранного агента. Проверь опустевшие Уши/Голос и подключи их заново.

1. Открой **Самопроверку** или выполни `bender doctor`. Там есть статусы и подсказки: база, сейф, настройки, модели, каналы, бекапы, диск, Сторож и слоты. Обычная проверка не отправляет запросы к моделям и не исправляет файлы. Необязательная проверка ролей может стоить денег; голос, если выключен, не включается. На Linux видны RSS, потоки, дескрипторы и накопленные счётчики записи — сравни их сейчас и спустя сутки. На других ОС эти метрики могут быть недоступны.
2. Для сообщения о проблеме выполни `bender report` или «Самопроверка → Подготовить отчёт». Просмотри состав и сохрани ZIP. Без терминала с вводом CLI показывает только состав; после просмотра повтори `bender report --yes`. В отчёте только технические поля: ключи, адреса, разговоры, память и произвольный текст исключены. Поэтому добавь своими словами, что делал и что увидел. Не прикладывай `data/` или сейф.
3. При аварии Сторож перезапускает ядро; прерванный ход отмечается, действия автоматически не повторяются. При нескольких падениях включается безопасный режим без каналов, модулей и Сердца. Его можно запустить самому: `bender run --safe`. Отказ из-за битой базы/сейфа/личности/настроек/boot сопровождается подсказкой: сначала сохрани повреждённые файлы, затем восстанови целую копию. Doctor/report доступны и без запуска ядра.
4. После неудачного обновления Сторож возвращает прежний слот. Ручной откат — **Версии и откат**; нужен прежний слот и обычный запуск со Сторожем. Откат программы не откатывает данные. Подписанный пакет или собственную разработку хозяин выбирает и просматривает сам; агент ядро не редактирует.

Заранее выбери в **Бекапах** папку на другом носителе, сделай снимок и полную проверку. Расписание включается там же. Копии не шифруются; сейф по умолчанию исключён, его включение — отдельный выбор. Восстанавливай в **новую папку**, просмотри состав, затем запусти Бендера с `--data` этой папки. Живая база не подменяется. Для проверки достаточно пульта или `bender backup list` и `bender backup verify --full` после выбора носителя. Если носитель сбоит, «Починить бекапы» (или `bender backup repair`) сверяет копии: целые блоки и описи подтягиваются со второй папки, битые убираются, потом сохраняется свежий снимок. Снимок сам не отменяется из-за одного сбойного носителя или пропавшего файла — пока цела хоть одна копия, он пишется в неё и сообщает о пропуске; при сбое чтения Бендер один раз чинит и повторяет сам. В Telegram то же: `/backup` (кнопки «Сохранить», «Проверить», «Починить»), `/update` (в личке: «Обновить» или «без бекапа»), `/doctor`, `/journal`, `/load`.

## Когда он спрашивает


В исходном профиле «Осторожный» опасные действия и внешние отправки требуют решения Предохранителя: ты видишь действие и выбираешь допуск. Расширение прав, доверие к чужому коду и отключение защиты выбирает только хозяин. Неодобренный пакет не становится доверенным от просьбы модели. Ядро агент не правит даже по карточке; разрешены свои навыки и отдельные модули.

Бытовые предпочтения агент меняет сам: время сна/тихие часы, язык, внешний вид и голос. Значки ✓/?/🔒 в настройках показывают его права. Можно попросить сменить fast на другую подключённую модель с причиной — строка сохранится в домашнем канале и журнале. Переход на платный ключ вместо подписки/локальной модели и удаление запасных требуют подтверждения.

Ты можешь сам выбрать более свободный профиль или выключить Предохранитель — тогда обычные действия могут выполняться без вопросов. Защитные границы ядра и служебных данных сохраняются. Не выбирай расширенные права до собственной проверки поведения.

На карточке четыре ответа. «Разрешить один раз» — только это действие. «В этом разговоре» — такой вид действий (команды, запись файлов, вызовы MCP…) без вопросов до конца разговора: до /new или перезапуска; конец хода его не отменяет, а помощники команды из этого разговора тоже не переспрашивают. «Всегда: …» запоминает правило не по точному тексту, а шире — программу (`команды git`), папку, сайт или весь MCP-сервер; на кнопке написано, что именно. Цепочку команд через `;`, `&&` или `|` правило по программе не покрывает. Правила видны и удаляются в Предохранитель → Правила хозяина. Если одновременно висят несколько карточек, ответ «в этом разговоре» или «всегда» закрывает и те, что он покрывает. В «Доверии» ход, прочитавший сайт или ответ внешнего тула, переспрашивает только отправку чужим (сеть, сообщения не тебе, секреты); в «Осторожном» и «Обычном» — всё, чем можно вынести данные. Но то, на что ты нажал «Всегда», после чужого текста не переспрашивается — например, все тулы MCP-сервера, хотя ответ каждого тула и есть чужой текст. Исключение — та же отправка чужим: на такой кнопке так и написано «после чужого текста всё равно спрошу». Повторное «Всегда» на то же самое не создаёт второе правило. Выключенный Предохранитель не спрашивает и про файл тебе и переписку агентов; только публичный ответ в группу после чужого текста по-прежнему подтверждаешь ты. Профиль помощника из шаблона прав уступает тому, что ты выбрал в его Предохранителе; явный профиль в Стая → Права сильнее.

Теперь пройди [ПРИЁМКА.md](ПРИЁМКА.md) на своей машине с настоящей моделью. Результаты живой приёмки определят следующую задачу.

Подписки, у которых нет официального пути для сторонних программ, можно собрать за OpenAI-совместимым посредником вроде OmniRoute: Бендер шлёт туда обычные запросы. Но если посредник входит в чужой сервис твоим аккаунтом, это вне правил сервиса. Google прямо пишет, что доступ к Antigravity сторонним ПО нарушает его условия и может кончиться блокировкой аккаунта. Без такого риска — ключ API (для Gemini — пресет Google Gemini).

## Манеры речи

Агент тот же, меняется только то, как он говорит. Пульт → Я → «Манера речи»: выбери одну из заготовок («Вдумчивый собеседник» в духе Claude, «Тихий AGI», «Сократ», «ИИ-вайфу») или «Свой голос». Там же можно добавить свою манеру, поправить заготовку и посмотреть, как её увидит агент. В Telegram — `/style` с кнопками или `/style off`; в терминале — `bender style use Сократ`, `bender style off`, `bender style list --agent ИМЯ`.

Агент может переключить манеру сам, если попросить словами («будь потише», «давай как Сократ»). В профиле «Осторожный» Предохранитель спросит тебя, в «Обычном» и «Доверии» — нет. Тексты манер пишет только хозяин. Выключатель всех манер и напоминание в каждом ходе — Настройки → Манера речи. Проверить без модели: `bender try manner Сократ`.

## Команды и SSH в стае

Когда агентов много, а машина слабая (Raspberry Pi), Бендер сам притормаживает фон: если цикл отвечает на стук Сторожа дольше секунды, плановые дела (пульс, сон, бекап, проверка обновлений) и безлюдные ходы ждут до 30 секунд, а разговор с тобой не ждёт никогда. Агенты стаи просыпаются не разом, а с разбросом в полминуты. Отключается настройкой «Стая → Притормаживать фон при перегрузке». Посмотреть, кто что делает и когда цикл вставал, можно командой `/load` в Telegram; подробный стек зависания лежит в local/stalls.txt. Пульт запрашивает состояние не чаще раза в две секунды, а траты за день считаются раз в несколько секунд, а не на каждое событие.

Стая → Права задаёт потолок выбранного агента. Полный наследует профиль из Настройки → Предохранитель и имеет команды/сеть/SSH. Помощник по умолчанию без команд и с осторожным профилем; экран Предохранителя показывает действующий профиль и источник. Главному агенту OpenClaw при новом переезде предлагается Полный, остальным — Помощник; шаблон выбирается в плане. Старому импорту пульт один раз предложит повышение, которое решаешь ты.

С bubblewrap сетевая команда сохраняет закрытые данные соседей и служебные данные. Право SSH открывает ключи только на чтение, known_hosts на запись и сокет ssh-agent. Команда ssh идёт с `allow_net=true`: без сети она не подключится. Если агент хозяйничает на твоих машинах и в локальной сети, песочницу можно выключить: Права → Песочница команд → «Без песочницы»; подтверждения и жёсткий список останутся. Терминала у команды нет: для узла с настроенным ключом можно попросить `ssh -o BatchMode=yes -o StrictHostKeyChecking=accept-new узел uptime`. Пароль нужно настроить вне агентного хода. При списке разрешённых узлов используй сетевые тулы; общая сеть команды не умеет ограничивать домены.

Урезанный шаблон требует bubblewrap: `sudo apt install bubblewrap`. Явный выключатель «Стая → Права → Требовать изоляцию команд» разрешает запуск без него. Полный по умолчанию допускает такой запуск. Без bubblewrap команды видят файлы других агентов и домашние ключи: это доступ с правами пользователя ОС.

## Запуск, перезапуск и выключение

В «Состоянии» и «Настройках» карточка «Состояние запуска» показывает PID и как запущен Бендер. Кнопки «Перезапустить» и «Выключить» есть и в боковой панели. Подтверждение относится ко всей стае: можно дождаться текущих ходов или прервать их. При ожидании новые ходы не начинаются. Если ход завис, стоп-кран завершит его. Из Telegram в личке хозяина: `/restart` и `/shutdown`, затем кнопка; после перезапуска придёт «Снова тут, не было N с» в тот же чат/тему. Агентный тул restart всегда просит отдельное подтверждение, выключение ему не выдано.

Ручной запуск `bender` работает через Сторожа: перезапуск поднимает ядро снова, выключение чисто завершает оба процесса. Запустить снова: `bender`. SIGTERM и Ctrl+C тоже останавливают ручной запуск. У службы systemd выключение — чистый выход без автоматического возврата; запустить снова: `systemctl --user start bender`. При `bender run --no-watchdog` перезапуск недоступен, выключение работает. Поля настроек, требующие перезапуска, отмечаются плашкой с кнопкой.

Автозапуск доступен отдельно от установки программы:

```sh
bender service status
bender service install
bender service remove
```

Установленный локальный голос — отдельная служба:

```sh
bender service install --voice
bender service status --voice
bender service remove --voice
```

Флаг --voice не скачивает модели и не меняет роли; сначала установи голос. `bash install.sh --service` вызывает ту же команду для ядра. Служба получает PATH установки, явную папку данных и программу; поддерживаются systemd пользователя и Termux:Boot. Свою папку передавай перед командой: `bender --data /путь/к/данным service status`. Если работает ручной процесс, установка автозапуска не создаёт рядом второй: она называет PID, объясняет Ctrl+C/SIGTERM, а службу запустишь после его остановки. Вторая работающая копия на той же папке данных отвергается до открытия базы и сообщает PID первой; обычные CLI настроек остаются доступны.

Проверка без остановки: `bender try lifecycle`; Полигон → Запуск и остановка.

## Уши и Голос любого агента

Локальные GigaAM/Piper ставятся один раз в отдельный пакет. Ядру сторонние библиотеки не нужны:

```sh
bender voice install
bender voice status
bender voice connect all
```

Установка подключает постоянных неархивных агентов без своих Ушей/Голоса; свои цепочки сохраняются. `bender voice install --agent main` явно выбирает одного агента. Повторная установка сверяет хеши файлов и не загружает совпавшие модели заново. Голосовую службу после изменения порта/потоков/моделей перезапусти отдельно: `systemctl --user restart bender-voice.service`; при ручном voice serve — останови и запусти снова. Перезапуск ядра для новых настроек и ролей не нужен.

Уже установленный голос подключается без загрузки: `bender voice connect main` или **Модели → Локальный голос → Подключить этому агенту**. В выборе Ушей/Голоса есть установленный локальный вариант. Карточка показывает подключение у каждого агента. Агент сам может вызвать `voice_connect`: подключает только себе бесплатную локальную цепочку. Установка пакета, запуск службы и передача сырого звука главной модели остаются выбором хозяина.

`/voice on` включает голос, `/voice off` выключает, `/voice reply` включает ответы голосом в Telegram. Попроси «ответь голосом» — агент может вызвать `speak` в этом разговоре. В личке/теме отправляется настоящий OGG/Opus, при недоступности — текст с причиной. В пульте появится звуковое вложение; в группы и чужим адресатам этот тул не отправляет. Настройки остаются в Настройки → Голос, сами модели — в ролях Уши/Голос. Паспорт и `about_me` показывают реальные цепочки, режим слушания и включён ли ответ голосом. Расшифровка в истории отмечена как голосовое; пересланная речь остаётся недоверенной.
## Картинки и аудиофайлы

Фотографии доходят до модели и при неизвестном каталоге. В **Модели → роль → Возможности** можно выбрать зрение/слух: да, нет или неизвестно. Неизвестно означает попытку; явный отказ на медиа сохраняется с датой и причиной. Для проверки нажми «Проверить зрение» — один короткий запрос с цветным PNG, без твоих разговоров. «Проверить слух» использует короткий WAV от установленного и включённого локального Piper; без него показана причина недоступности.

Если главная не видит, настроенная роль **Зрение** может описать картинку. Главная получит описание с пометкой недоверенного источника и путь к исходнику. Выключатели — Настройки → Вложения: передача фотографий, запасное описание, запоминание отказов. Если неизвестно, видит ли главная, — так бывает у роутеров вроде OmniRoute, где за одним именем разные модели, — по умолчанию она получает и картинку, и описание Зрением: увидит сама или прочтёт описание. Это настройка «Если неизвестно, видит ли модель» там же; описание работает, когда в роль Зрение назначена другая модель. `bender doctor` пишет, кто описывает картинки, без запросов к моделям. Для ChatGPT зрение включено; нативный слух остаётся неизвестным до фактической проверки. Некоторые адаптеры не имеют протокола звука — тогда работают Уши, это видно в паспорте.

Музыка и запись, присланная документом (WAV/MP3/OGG/FLAC/M4A), идут через **Уши**; они всегда недоверенные, даже если файл прислал хозяин. Длительность берётся из файла, не из поля отправителя. Лимиты размера/секунд — Настройки → Голос. Если заголовки не читаются, нужен включённый локальный декодер или другая запись в WAV; исходник остаётся в inbox. Видео/кружок не получает выдуманной расшифровки: канал сообщает причину, путь и как вручную извлечь дорожку.

Без запроса модели: `bender try media`. Явная проба в терминале: `bender try media ПРОВАЙДЕР МОДЕЛЬ vision` (или audio_input). Если модель приняла картинку, но ответила, что не видит её (так бывает у шлюзов, которые молча выбрасывают вложение), проба оставит «неизвестно» и покажет кнопку «Поставить «Нет»» — тогда картинки будет описывать Зрение. Идентификаторы видны в выводе первой команды. Эти же проверки доступны через ссылку «Зрение и слух моделей» на Полигоне.

## Пересмотреть файл

Попроси агента открыть картинку или запись через `read_file` по сохранённому пути. Вложения каналов лежат в своей папке `work/inbox/дата/…`; относительный путь начинается с `inbox/`. Картинка идёт главной модели или роли Зрение, аудио — Ушам; сырой звук получает только цепочка и режим, разрешённые хозяином. Это всегда недоверенные данные. Доступ к пути проверяет Предохранитель. Картинка, присланная файлом («без сжатия»), приходит модели так же, как фото, если это по содержимому JPEG, PNG, GIF или WebP до 3,75 МБ (5 МБ в base64 — предел моделей); больше или SVG/HEIC — модель получит путь и подсказку. Картинки из результатов MCP-тулов (например, скриншоты) тоже доходят до модели и сохраняются во входящих. Тулом `look` агент сам просит роль Зрение посмотреть картинку и ответить на вопрос — это трата модели Зрения; выключатель «Тул look» во Вложениях.

Картинки из писем: Почта → «Картинки из писем» — выключено, от знакомых (умолчание: адреса из «Знакомых» и твои) или от всех. Сохранённые картинки агент видит, когда читает письмо. Адрес отправителя можно подделать, поэтому картинки из писем всегда недоверенные.

По умолчанию за ход можно открыть четыре медиафайла общей суммой до 20 МБ, каждый до лимита входящего файла. Настройки → Вложения меняют эти пределы и число ходов, в которых картинка/звук ещё посылаются модели (по умолчанию три). После этого в контексте остаётся путь; попроси `read_file` снова. Исходный файл и сохранённая история не удаляются.

## Команды, правки и цитаты

`/status`, другие команды и нажатия кнопок Telegram оставляют короткую служебную строку: агент увидит её при следующем обращении к модели. Сами строки не запускают ход. Они не заменяют твоё поручение; `/report` отмечает только факт вызова. Настройки → Telegram → «Служебные события Telegram в истории»: выключено, кратко, подробно.

Если исправить известное входящее сообщение, в том же разговоре появится «было → стало». Идущий ход получит исправление на безопасной границе, завершённый сам не возобновится. Правка команды не выполняет её повторно. Выключенный режим скрывает и такие строки. В пульте «Ответить» у реплики добавляет цитату к следующему сообщению; выбери текст и отправь уточнение. У реплик показан канал, у Telegram — также тема/группа. Цитаты и исправления сохраняют пометку недоверенного источника.

## Где прочитать письмо другому агенту

Агент, которому написал другой агент стаи, работает со своими обычными правами. Если цепочку начал ты, его вопросы и карточки приходят тебе. Если начало пульс или расписание — спрашивать некого, и он ищет другой путь. Чужие память и рабочие папки агентов закрыты всегда, даже при выключенном Предохранителе; папку программы и папку данных целиком посмотреть можно — закрытое внутри просто пропускается.


Выбери получателя в верхнем списке стаи, открой разговор и раздел **Переписка** в списке чатов. Там отправитель, вызванные тулы и ответ. Нить только для чтения; новое поручение пиши в обычном чате. В главном чате получателя есть короткий итог письма с кнопкой «Открыть переписку», которая не запускает модель. За этой строкой агент помнит суть: само письмо, какие тулы вызывал и что ответил, — поэтому потом в разговоре с тобой знает, что делал по письму. Если отправитель писал не из главного чата (из задачи, пульса, расписания), запись «Я писал агенту …» с ответом появляется и в его главном чате. А получатель, начиная работу по письму, видит хвост своего главного чата с тобой с прошлого письма этого собеседника — то есть в курсе того, о чём вы только что говорили.

В Telegram `/chats` → «Переписка (только чтение)» показывает хвост нити; обычные сообщения продолжают идти в выбранный разговор. Отключить строки об итогах можно в «Общение стаи» или Настройки → Общение стаи → «Итог письма в главном чате получателя».

## Старые разговоры: сон и сжатие

**Сон** разбирает долговременную память: дневник, факты, полезные выводы. Разговор во сне не сжимается. Сон наступает около 03:00, если Бендер запущен, Сердце включено, ты молчишь 30 минут и с прошлого сна есть новое; не вышло до 06:00 — ночь пропущена. Агент помнит свой последний сон (раздел «Твой сон» в промпте) и может перечитать DREAMS.md. Снов нет — `/sleep` в Telegram или экран «Сны» скажут почему. Ядро памяти (MEMORY.md, USER.md) без тебя не чистится. Когда оно заполнено на 85%, сон предлагает, что убрать или склеить; попросить самому — пульт → Сны → «Предложить уборку», `/sleep tidy` или словами агенту. Применяешь ты: в пульте галочками, в Telegram кнопкой. Прежний вид — в `self/history/`. **Сжатие** пересказывает начало только для следующего запроса к модели — само, когда хвост занял 85% бюджета, или когда попросишь (тогда и короткий разговор, остаётся последняя четверть); сами сообщения навсегда остаются в SQLite. Попросить сжать сейчас можно кнопкой **«Сжать сейчас»** в чате/Памяти или `/compact` в Telegram. Идущего хода нужно дождаться; выключатель сжатия — Настройки → Память. Пересказ сохраняет даты, текущую цель и пометки недоверенного.

Агент находит старое тулом `sessions` (название, слова, вид/канал, даты), затем читает `session_read` страницами около даты или сообщения. Импорт OpenClaw входит. Находка `recall` содержит точный id разговора/реплики, по которому можно открыть контекст. Он читает только своё пространство; старые поручения остаются справкой. Длинные реплики продолжаются по `text_offset`, старые картинки — `read_file` по сохранённому пути. Выключатели тулов — Настройки → Тулы.

Для проверки без запроса к модели: `bender try sessions`, `bender try sessions read ID` (подставь id из списка); для другого агента добавь его имя последним аргументом. `bender try compact` показывает бюджет/пересказ, `bender try compact now` делает явное сжатие подключённой Быстрой моделью.

## Кому из стаи виден MCP-сервер

На экране **MCP** у каждого сервера есть строка «Кому доступен». По умолчанию отмечено «всем». Сними эту галочку и отметь нужных агентов: остальные не увидят тулы и ресурсы сервера и не смогут его вызвать. Помощник команды пользуется выбором агента, который его позвал. Выбор не сбрасывает одобрение тулов. Помощникам нужны ещё права на MCP: Стая → Права (способность mcp.call и группа mcp).

Сервер, который запускается программой на твоей машине (stdio), работает одним процессом на всю стаю: юзербот не получит две сессии одного аккаунта. Что сервер пишет в свой журнал — на экране MCP, «Журнал сервера» (код выхода, последняя ошибка, вывод). Агент видит то же тулом `mcp_diagnose`, без значений секретов. Если тулы пишут «нужно одобрение», а кнопки нет — нажми «Обнаружить тулы»: появится разница и кнопка «Одобрить».

## Ресурсы и шаблоны внешнего MCP

На экране **MCP** включи «Ресурсы и шаблоны MCP», выбери сервер и нажми **«Обнаружить ресурсы и шаблоны»**. Просмотри полные определения, затем одобри каталог. Это отдельное одобрение: прежние тулы сохраняются. Изменившееся определение потребует нового просмотра.

В Полигоне выбери **mcp_content**: `{"action":"list"}` показывает одобренное, `{"action":"read","server":"имя","uri":"адрес из каталога"}` читает ресурс, `{"action":"prompt","server":"имя","name":"шаблон","arguments":{"тема":"проверка"}}` получает текстовый шаблон. Перед чтением Предохранитель проверяет вызов. URI получает только MCP-сервер; двоичные данные пока показаны метаданными. Текст шаблона остаётся недоверенной справкой.

Из терминала: `bender try mcp content ИМЯ` обнаруживает каталог, `bender try tool mcp_content '{"action":"list"}'` показывает одобренное. Выключатель всей возможности — MCP/Настройки → Внешние MCP-серверы, самого тула — Настройки → Тулы.

Если внешний сервер требует старый отдельный поток SSE, при добавлении выбери **«Старый HTTP+SSE»** и укажи его входящий адрес. Сервер сообщит адрес для отправки; Бендер примет его только на том же origin. Дальше — обычное обнаружение/просмотр/одобрение тулов или ресурсов. Импорт такого подключения оставляет его выключенным. После потери ответа проверь результат на сервере: действие само не повторяется.

## Если MCP-сервер просит помощь клиента

На экране **MCP** включи **«Встречные запросы MCP»**, затем в нужном подключении раскрой **«Что сервер может попросить у Бендера»**. Выбери отдельно список папок, текст у Быстрой модели или форму/ссылку хозяину. Изменение требует заново обнаружить и одобрить определения сервера. Предохранитель спросит о каждом недоверенном встречном запросе.

Папки показываются только именем и URI после проверки прав вызывающего — их файлы не читаются. Для запроса к модели нужна настроенная **Быстрая**: у неё не будет твоей истории, памяти или тулов. По умолчанию ответ до 1024 токенов, встречных запросов до четырёх за ход; пределы и ожидание хозяина (180 с) — Настройки → Внешние MCP-серверы.

Форма появится в **MCP** с именем сервера/агента и пояснением, кому уйдёт ответ. Введи обычные данные и нажми **«Отправить серверу»**, либо откажи/закрой. Пароли, ключи и токены в неё не вводи; для входа используй сайт сервиса по явно показанной HTTPS-ссылке и кнопку **«Я завершил на сайте»**. В отсутствие хозяина форма отменяется. Ответ остаётся данными для сервера и не начинает разговор с агентом.

## Вход на сайт MCP-сервиса

На экране **MCP** включи **«Вход OAuth в MCP-сервисы»**. У HTTP/SSE-подключения нажми **«Настроить вход OAuth»**, прочитай метаданные и выбери сервер входа. Проверь показанные адрес сервиса, издателя, права и адрес возврата. Затем укажи выданный сервисом client_id либо выбери поддерживаемую им регистрацию/HTTPS-документ клиента. Секрет клиента, если нужен, уйдёт в сейф.

Нажми **«Подготовить вход»** и открой показанную ссылку. После согласия на сайте вернись по ссылке в пульт. Теперь заново обнаружь, просмотри и одобри определения сервера — полученный токен не заменяет одобрение тулов. Если срок истёк, нажми **«Обновить токен»**; автоматического повтора действия нет. **«Убрать вход из Бендера»** удаляет локальное подключение токена; для отзыва у сервиса открой настройки самого сервиса.

Для HTTPS-документа клиента пульт должен быть доступен серверу входа по HTTPS; локальный адрес чужому сайту обычно недоступен. С заранее зарегистрированным клиентом возможен возврат на localhost по HTTP. Проверка без сети: `bender try mcp oauth ИМЯ` или MCP на Полигоне. Возможность целиком отключается тем же переключателем.

## Фоновые задачи и события MCP

В **MCP** включи **«Фоновые задачи MCP 2026»**, затем в форме нужного подключения — **«Принимать фоновые задачи MCP 2026 от этого сервера»**. Заново обнаружь и одобри определения. Если сервер поддерживает расширение, обычный вызов может вернуть задачу: она появится сверху экрана MCP. **«Проверить статус»** получает её результат, **«Ответить на запрос задачи»** запускает защищённую форму/ввод. **«Попросить отмену»** передаёт просьбу серверу и не обещает отката. **«Удалить локальную запись»** только убирает запись у Бендера.

Из терминала `bender try mcp tasks` показывает записи без сети. На Полигоне выбери **mcp_tasks**: action=list; затем action=status/input/cancel и task=локальный id из списка. По умолчанию фонового опроса нет, результат сам не запускает разговор с моделью. До 100 записей на агента: завершённые можно удалить локально.

Для HTTP MCP 2026 включи **«Подписки MCP 2026»**, раскрой **«Подписка на события»** у сервера и нажми **«Открыть подписку»**. Можно добавить события одобренных ресурсов и собственных задач. Пульт покажет, что сервер действительно подтвердил. Изменившиеся каталоги требуют нового обнаружения/просмотра; файлы/ресурсы сами не читаются. Поток можно закрыть кнопкой. После обрыва открой заново вручную; stdio/старый HTTP+SSE и Tasks 2025 этих возможностей пока не объявляют.

## Matrix отдельным модулем

В **Связях → Matrix** нажми **«Установить Matrix в карантин»**. В **Модулях** просмотри пакет, одобри его, обнаружь и одобри определения инструментов. Создай отдельную учётную запись бота и комнату **без шифрования**, только с собой и ботом. Существующую шифрованную комнату этот модуль не обслуживает; её защиту он не меняет.

В Связях введи HTTPS-адрес домашнего сервера, полный ID комнаты `!…:сервер`, токен бота и выбери агента. **«Сохранить Matrix выключенным»**, затем **«Подключить комнату Matrix»**; подтверди вход в выбранную комнату в Предохранителе. После первого успешного `/sync` получи код и напиши `/pair КОД` в этой комнате. Проверка не чаще минуты, поэтому привязка/новое сообщение могут ждать до минуты.

Сообщения, фото/файлы до 20 МБ и реакции идут в отдельный разговор выбранного агента. Он отвечает туда, может использовать обычные send_message/send_file/react и ссылаться на `[Matrix #…]`. Вложения недоверенные, посторонний участник/шифрование блокирует канал. Кнопка **«Выключить Matrix»** останавливает процессы, **«Забыть хозяина»** удаляет привязку. Интервал/предел файлов — Настройки → Matrix. Проверка без сети: `bender try matrix`; явная проверка сервера/комнаты — `bender try matrix check`.

После переноса OpenClaw здесь появятся предложения адреса/комнат выбранного агента. Они только заполняют форму; токен ищи отдельно в Сейфе, если разрешал перенос секретов. Привяжи хозяина заново. Если источник использовал E2EE, создай другую комнату без шифрования для этого модуля.

## Колонка вместо Алисы

Экспериментально: проверено на Яндекс Станции Лайт 2. На других колонках может не работать.

Бендер может слышать и говорить через взломанную Яндекс Станцию. Сам взлом Бендер не делает и на колонку ничего не ставит. На колонке должен работать [Pulsar](https://github.com/Morvex885/pulsar) — открытая программа, которая заменяет Алису. Слово вызова («Алиса» или «Яндекс») и очистка звука от эха и шума остаются на колонке. Распознаёт, думает и отвечает уже Бендер, Яндекс в этом не участвует.

1. Поставь Pulsar по его инструкции. Ключ шифрования API на колонке не задавай: Бендер пока подключается без шифрования, поэтому колонка должна быть в доверенной домашней сети.
2. У агента должны быть подключены **Уши** и **Голос** (Настройки → Голос, роли «Уши» и «Голос»). Подойдут любые цепочки: облачные или локальные.
3. В **Связь → Колонки** (превью) нажми «Найти в сети» или впиши адрес и включи «Колонки включены»; то же можно списком в **Настройки → Колонки**, например `[{"name":"Кухня","host":"192.0.2.40"}]`. Поиск работает, только если сеть пропускает mDNS. Свой агент для колонки задаётся полем `agent_id`; передача разговора (агент вызывает hand_over) держится, пока ты не назначишь колонке другого. Главный отвечает, только когда выбрать некого: если выбранный агент временно недоступен (стая выключена, сбой загрузки), отвечает агент колонки, потом агент по умолчанию, потом главный, а выбор остаётся и вернётся сам; если агента убрали в архив, выбор отпадает.
4. Скажи колонке «Алиса, …». Фраза попадёт в главный разговор агента с пометкой «[Колонка «Кухня»]», а ответ на неё прозвучит из колонки. Если нужен отдельный чат «Колонка · Кухня», выбери «Разговор колонки → Отдельный».

Агент знает, что говорит вслух: отвечает коротко, без разметки и ссылок, а если не расслышал, переспрашивает. Если он закончит ответ вопросом, колонка послушает ответ без слова вызова (настройка «Продолжать разговор»). Если работа долгая, агент сразу скажет «займусь», колонка освободится, а итог он объявит сам, когда закончит. Сколько колонка ждёт ответа, задаёт настройка «Сколько колонка ждёт ответа».

Если последний раз ты говорил с агентом через колонку, она становится его «последним каналом». Всё, что агент скажет сам — итог сердцебиения, новости после обновления, его уведомления, — прозвучит из колонки, пока ты снова не напишешь в Telegram или пульт. В тихие часы, без связи с колонкой или пока она занята разговором, это уходит в Telegram и не теряется. Выключить — настройка «Колонка — последний канал».

Общие уведомления Бендера колонка тоже может произносить: по умолчанию только тревоги. Можно выбрать «Все» или «Ничего». В тихие часы вслух звучат только тревоги.

Чтобы колонка отвечала быстрее, есть «Модель для колонки → Быстрая» (роль «Быстрая» агента) и «Усилие для колонки» (например, «Низкое»). Они действуют только на ходы, которые начала колонка; по умолчанию всё как у агента.

Подтверждения Предохранителя можно давать голосом: настройка «Подтверждения голосом → Голосом тоже». Если вопрос возник в разговоре, который ты вёл через колонку за последние 10 минут, колонка спросит вслух и сразу послушает ответ: «да», «да в разговоре», «да всегда» или «нет». Кнопка в Telegram и пульте работает как раньше, засчитывается первый ответ. Колонку слышат все в комнате, поэтому по умолчанию подтверждения голосом выключены.

Превью: «Стоп» (настройка «Колонки → Стоп останавливает агента», включена) прерывает ответ и ход агента, если колонка сообщает слово остановки. «Кольцо показывает состояние» (выключено) красит свет колонки: слушает — синий, думает — жёлтый, говорит — зелёный.

Звук ответа колонка забирает с компьютера Бендера по одноразовой ссылке. Если колонка проигрывает звук ошибки, а в журнале Pulsar (`/data/pulsar/ctl.sh log`) скачивание обрывается через 15 секунд, порт закрыт брандмауэром: `sudo ufw allow 8771/tcp`. Для этого Бендер открывает в домашней сети отдельную маленькую раздачу на порту 8771. Пульт при этом по-прежнему открыт только на этом компьютере. Порт и адрес раздачи меняются в настройках колонок.

Колонку слышат все, кто рядом, поэтому говорить с агентом может не только хозяин. Опасные действия всё равно требуют подтверждения в пульте или Telegram.

Проверка без сети: `bender try speakers`. Явная проверка связи с колонкой: `bender try speakers check 192.0.2.40`.

## Свой аккаунт Telegram у агента

Агенту можно дать настоящий аккаунт Telegram: он будет писать в личках, группах и каналах как человек. Лучше завести для этого отдельный номер: Telegram может ограничить аккаунт за автоматизацию.

Вверху пульта выбери агента, затем **Связи → Аккаунт Telegram агента**:

1. **«Установить Telethon»**. Библиотека ставится в отдельную папку Бендера и не трогает системный Python. **«Удалить Telethon»** стирает эту папку целиком.
2. Сохрани `api_id` и `api_hash` — их выдаёт my.telegram.org → API development tools.
3. Отметь, что понимаешь риск, введи номер, затем код из Telegram (и пароль двухэтапной проверки, если он есть).
4. **«Получить код привязки»** и отправь этот код со своего личного аккаунта в личку аккаунту агента. Теперь агент узнаёт тебя.
5. В списке **«Кого видит и кому отвечает»** найди чаты и включи нужные. Пока список пуст, аккаунт никого не видит и никому не отвечает.

У каждого чата три настройки: **«Видит»** — агент получает сообщения как чужой, недоверенный текст; **«Будить»** — никогда, по упоминанию или на каждое сообщение; **«Отвечает»** — ответ агента уходит в этот чат.

В чатах из списка агент действует сам. Чтение и отправка в другие чаты, смена профиля, вступление и выход из чатов приходят тебе на одобрение. Переключатель **«Весь аккаунт»** снимает эти вопросы. Прямые вызовы API Telegram спрашивают всегда.

Одобрения и уведомления этого агента по умолчанию приходят в общий бот, там есть кнопки. Можно перевести их **«В чат аккаунта»**: тогда отвечаешь словами «да», «да в разговоре», «да всегда» или «нет».

В личке с аккаунтом работают команды `/new`, `/stop`, `/status`, `/estop`, `/resume` и `/help`.

Аккаунту нужен прямой доступ к серверам Telegram. Проверка без сети: `BENDER_USERBOT_HELPER=tests/fixtures/fake_userbot.py python3 -m bender run`, код входа `12345`.

## Агент в другой программе

В «Связях» включи API и создай ключ. У выбранного агента в «Правах» отдельная строка API: по умолчанию «Помощник», можно выключить или выбрать более узкий профиль. Обычный разговор в пульте сохраняет свои права. В программе-клиенте добавь OpenAI-совместимый адрес `http://127.0.0.1:8770/v1` и этот ключ, выбери модель «bender/main» или другого агента из каталога. Если порт другой, возьми его из ссылки пульта.

Для постоянного серверного разговора клиент передаёт уникальный для своего чата `user` либо заголовок `X-Bender-Chat` (он важнее). Без id каждый запрос создаёт новый разговор и берёт переданную историю. Не используй один id для разных клиентских чатов. Если клиент задаёт постоянный user в настройках профиля, для разных чатов нужны разные значения или профили. Собственные функции клиента через API не исполняются: агент использует свои разрешённые инструменты. Планируемое из API задание с моделью потребует твоего отдельного согласия.

Проверить без модели/сети: `bender try api` или Полигон → api. Выключение API агента или смена ключа отзывает его текущие API-ходы.

## Несколько агентов и чатов

В верхней полосе пульта выбери агента и его чат; две вкладки могут работать с разными агентами одновременно. На экране «Агенты» создай нового из шаблона или роли команды, задай имя, затем проверь его «Права». У агента свои личность, память, разговоры и роли моделей, общий каталог провайдеров и разрешённые хозяином ключи. «Помощник» не получает команды ОС от одного разрешающего правила; потолок расширяешь ты. Архив скрывает агента, экспорт сохраняет переносимый пакет; перед удалением понадобится подтверждение.

В переезде OpenClaw/Hermes/заметок Claude Code обычный выбор — новый агент. Сначала посмотри план: несколько исходных агентов попадут в отдельных новых. Главная память не заменяется, неизвестные файлы остаются в архиве, секреты выбираются отдельно. Исходная установка только читается. Замена выбранного агента — отдельное явное действие после просмотра плана. Одному Telegram-боту не нужны два читающих процесса: источник сначала останови, новым агентам назначь темы.

«Стая → Общение» задаёт, кто кому может писать, с одобрением или без, и ограничения переписки. Попроси одного агента написать второму через message_agent; ответ придёт в отдельную переписку, не вместо твоего личного разговора. Письмо соседа не подтверждает согласия за хозяина. Временные помощники в «Задачах» наследуют пересечение прав родителя и роли; после работы их папки удаляются, результат остаётся. Кнопка «Оставить агента» сохраняет выбранного помощника постоянным.

## Telegram: агент, тема, файл

Отправь `/help`: там действующие команды и их назначение. `/agent` показывает стаю и выбирает, кто отвечает, `/chats` — его разговор, `/model` — модели по ролям и главную модель: сначала провайдер, потом модель. Кнопки выбора не устаревают: под старым сообщением они работают и после перезапуска, пока их не вытеснят три десятка новых; разовыми остаются только перезапуск, выключение, уборка памяти, отчёт и профиль бота. Для отдельных тем в личке включи темы у BotFather и «Связи → Telegram → Темы разговоров в личке», переподключи канал. `/new` создаст тему выбранного агента; привязка agent/session/topic сохраняется после перезапуска, простой ответ и Стоп попадают в свой разговор. Удалённая тема не возрождается автоматически. На сервере без поддержки тем останется обычный чат с причиной.

Фото, документы, голосовые и реакции обрабатываются в своём разговоре. Попроси отправить сохранённый файл обратно: доступ проверяется по папке и правам агента. Чужой/пересланный текст и подпись к файлу остаются недоверенными. Реакция — событие памяти, она сама не запускает новый ответ. Публичный аватар бота задаётся отдельно от визора пульта: «Связи → Публичное лицо общего бота», готовый JPG, просмотр и применение; либо отправь своё фото боту с `/avatar`. При добавлении в группу проверь список «Где находится бот» и явно разреши её; по умолчанию групповой канал закрыт.

Для русского голоса на Raspberry Pi нужна 64-битная ОС: `bender voice install`, затем `bender voice bench`. Установка ставит необязательный отдельный голосовой процесс, ядро остаётся без пакетов; повторная установка использует файлы с совпавшим хешем. Подключи Уши/Голос нужного агента кнопкой Моделей или `bender voice connect all`, включи голос и пришли короткое голосовое. `/voice reply` включает голосовые ответы. RTF измеряй на своём Pi: облачный тест кодека не измеряет скорость GigaAM/Piper. У моделей голоса нет подмены Главной ролью; при ошибке останутся текст и причина. Бесплатные облачные варианты/оговорки видны при подключении Ушей/Голоса.
